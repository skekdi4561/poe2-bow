# PoE2 시세 감정소

**POE2 공격 무기 — 이 예산으로 살 수 있는 최고 DPS는?**

▶ **https://skekdi4561.github.io/poe2-bow/**

거래소는 매물을 나열해줄 뿐 "얼마를 내면 DPS가 얼마나 오르는지"는 알려주지 않습니다.
이 사이트는 레어 무기 시세를 미리 떠서 **DPS 대비 가격 곡선**으로 보여줍니다.
활·쇠뇌·한손 철퇴·양손 철퇴·창·육척봉·부적 7종을 무기별로 따로 수집합니다
(검·도끼·단검 등은 아직 게임에 없어 매물이 0건입니다).

- 예산 슬라이더로 그 돈으로 살 수 있는 최고 DPS 확인
- DPS 밖 옵션(치명타·투사체 스킬 레벨 등)을 고집할 때 가격이 얼마나 오르는지 비교
- 모든 시세에 기준 시각 표시 — 언제 떠온 데이터인지 항상 보입니다
- **즉시 구매 가능 매물만 집계** — 귓속말을 안 받는 가격 조작 매물이 곡선에 들어오지 않습니다

## 안전한가요?

- **설치 없음, 로그인 없음.** 방문자는 미리 수집된 스냅샷(`latest.json`) 한 장만 읽습니다.
  방문자의 브라우저는 거래소 서버에 **아무 요청도 보내지 않습니다.**
- 계정 정보·쿠키·세션을 다루는 코드가 없습니다. 이 저장소가 소스 전체입니다 — 직접 확인하세요.
- 게임 클라이언트와의 접점이 없습니다(웹 전용 도구).

## 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 사이트 전체 (정적 한 페이지) |
| `latest.json` | 활 시세 스냅샷 — 방문자가 읽는 데이터 |
| `latest.<무기>.json` | 나머지 6종 스냅샷 (`latest.warstaff.json` 등) |
| `worker/` | 크라우드 수합 서버 (Cloudflare Worker) — 앱 사용자의 검색 응답을 익명으로 모읍니다 |
| `serve.py` | 수집기 + 로컬 실행기 (사이트 운영자용, 방문자는 필요 없음) |
| `poe2-bow-harvester.user.js` | 채집기(선택) — 거래소에서 구경한 매물을 본인 곡선에 합침. 추가 요청 0 |

## 시세 수집 (운영자용)

```
python serve.py --collect --every 3600 --push
```

무기 7종을 한 바퀴 돌리려면 `--weapons` 를 붙입니다(윈도우는 `start_collector.ps1`).
이력(`snapshots.db`)은 7일 밖 스냅샷을 스스로 정리하고, 스냅샷마다 리그가 찍혀 있어
리그가 바뀌어도 지난 리그 시세가 섞이지 않습니다.

거래소가 헤더로 알려주는 레이트 리밋에 맞춰 스스로 속도를 늦추며,
`--push` 는 수집한 스냅샷을 이 저장소로 밀어 올려 공개 페이지를 갱신합니다.

## 채집기 (선택 설치)

Tampermonkey 설치 후 [`poe2-bow-harvester.user.js`](https://skekdi4561.github.io/poe2-bow/poe2-bow-harvester.user.js) 를 열면 됩니다.
거래소 페이지가 **이미 받아온** 응답을 옆으로 복사할 뿐, 거래소로 요청을 새로 만들지 않습니다.
